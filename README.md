# Senku

Senku is a simple, quiet desktop companion for students designed to remove the friction between *knowing what to do* and *actually starting it*.

It gives your work a clean place to live. Senku does not organize, copy, move, or sync your files. Instead, it uses your existing file system to show your workspace, adding lightweight task reminders, multiple workspaces, and a daily scratch note to help you focus. Senku won't force you to study, but it makes taking that first step effortless.

## Why Senku?

Add the files, folders, links, or repositories needed for a specific task and set a reminder. When the time comes, Senku acts based on your preferred workflow:

* **Normal Mode:** Provides a gentle Windows notification at the task's start time. You can then open the attached resources yourself with one click.


* **Strict Mode:** Automatically opens all linked resources the exact moment the task starts. This is ideal when your goal is to eliminate every unnecessary click between the reminder and the actual work.



## Key Features

* **Live File Browser:** View your master folder exactly as it exists in Windows. Senku only remembers paths and preferences without modifying your actual system, though you can easily rename files directly within the app.


* **Multiple Workspaces:** Create separate environments—like one for a specific semester or placement preparation—each with its own master folder, tasks, and Strict Mode toggle.


* **Text-First Tasks:** Create one-time reminders that can be linked to local files, folders, URLs, or playlists.


* **Smart Task Actions:** Mark tasks as Done, Snooze them for later, or use **Reassign** to save your current progress while cleanly handing off the remaining work to a new schedule.


* **Failsafe Tracking:** Tasks seamlessly move to an Overdue view if unfinished, or to an Error view if a linked path breaks or goes missing so you never lose track of them.


* **Daily Scratch Notes:** A dedicated space for quick thoughts and daily brain dumps.
* **100% Local & Private:** Senku has no internet dependency; all data, settings, and tasks are stored locally as JSON files on your machine.



## Getting Started

Senku is simple by design. Explore the interface, set up your first master folder, and discover how seamless your workflow can be.

### Run Locally

You will need Node.js and npm installed on your system.

```bash
npm install
npm run dev

```
