1. Master Keyboard Shortcuts

Single-key shortcuts are active whenever focus is outside of an input, textarea, or content-editable field.

2. Spaces (Workspaces)

A Space represents a project or domain bound to a physical directory on your local filesystem.

  • Master Folder Binding: Point a Space to any local directory. The file tree panel allows browsing, opening files, and opening folders in Terminal or VS Code.
  • Path Availability Checking: Senku verifies local paths in launchpads and files, marking missing or relocated paths gracefully.
  • Parent Directory Navigation: Press R in file view to move up to the parent directory until reaching the master folder root.

3. Quiet Log & #senku

The Quiet Log is an immutable, append-only stream for thoughts, snippets, and execution logs.

  • Immutability: Logs cannot be edited once saved. This preserves authentic chronological history. Soft-delete is available.
  • Space Logs vs #senku: Logs added while a Space is active inherit the Space tag. Independent logs without an active Space wear the #senku badge.
  • One-Click Filtering: Click any space tag or the #senku badge in the feed to instantly filter. Press Esc to clear.
  • Multiline Capture: Press Shift+Enter in the capture box for code or multi-line paragraphs.

4. Notes & Bundle Folders

Distraction-free local Markdown notes manager.

  • Bundle Folders: Group notes into collapsible bundles (e.g. Units, Lectures).
  • Auto-Save: Keystrokes are saved immediately to local storage.
  • Hierarchical Export: Exporting all notes outputs a structured 4-level Markdown file: # All Space Notes → ## Space → ### Bundle → #### Note.

5. Launchpads

Multi-resource launch decks pairing files, folders, and web URLs.

  • 1-Click Launch: Opens all bundled resources simultaneously in your default browser and native OS applications.
  • Half-Split View: The Launchpads panel sits on the left with the Space's file tree on the right for quick resource drag/drop or reference.
  • Pin to Home: Star launchpads to display them directly on the Home dashboard.

6. Floating Quick Note Overlay

Compact 420px × 38px seamless pill window designed for zero-distraction capture.

  • Seamless Baseline Alignment: Mode badge and input text share identical baseline alignment.
  • Global Hotkey: Ctrl+Shift+Space invokes the overlay over any application.
  • Mode Toggle: Press Tab or click the badge to switch between appending to the active Note or saving to Quiet Log.
  • Auto-Expansion: Expands downward dynamically as you type multi-line notes.

7. Command Palette

Fuzzy-search command center invoked with Ctrl+K, Ctrl+P, or single-key P.

  • View Switching: Instant jump to Home (H), Overview (S), Launchpads (L), Notes (N), Quiet Log, or All Logs (G).
  • Direct Space Switching: Type a space name to switch to it immediately.
  • 1-Click Launch: Select any launchpad to execute it.
  • Direct Logging: Type text and press Enter to log instantly, or prefix with n <text> to append to active note.

8. Storage Architecture

Local directory: %APPDATA%\senku\ (Windows) • ~/.config/senku/ (Linux/macOS)
  • storage.json: Spaces, launchpads, bundles, and settings.
  • notes/*.md: Markdown files saved in human-readable plain text.
  • logs.md: Append-only plain text log entries.
