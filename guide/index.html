Foundation

Spaces: Local Workspaces That Bind to Your Folders

In Senku, a Space represents a project, subject, or focus area (e.g., Computer Networks, Compiler Design, SaaS App). Each Space links directly to a master folder on your local file system.

True Local Files

Master Folder Binding

Browse and open your project files and subfolders directly inside Senku without leaving your keyboard flow.

Instant Availability

Smart Path Verification

Senku verifies whether linked paths and files exist, highlighting missing or relocated files gracefully.

Total Independence

Switch Spaces in 1 Keystroke

Switch between spaces instantly via the Command Palette (Ctrl+K / P) or the workspace switcher.

💡 Pro Tip
When inside a subfolder in the File panel, press R to immediately navigate back up to the parent or root directory.
Memory

Quiet Log: Append-Only Stream of Consciousness

The Quiet Log is your digital scratchpad. It is intentionally append-only and immutable—you cannot edit past logs because logs capture the honest reality of what happened, when it happened.

Space Logs

Contextual Log Feed

Logs captured while a Space is active are automatically tagged to that Space, keeping your project notes coherent.

#senku Logs

Independent Global Logs

Quick thoughts captured outside any space wear the clean #senku badge. One click filters all independent logs.

Shift + Enter

Multiline Capture

Press Shift+Enter to type formatted code snippets, lists, or multi-line paragraphs. Press Enter to save.

Filtering & Exporting Logs

Click any space badge (or the #senku badge) in the log feed to instantly expand the search bar and filter by that exact tag. Press Esc to clear the filter instantly. Export your logs anytime to clean, date-grouped Markdown via the export button or Command Palette.

Writing

Notes & Bundle Folders: Distraction-Free Markdown

Senku's Notes editor is built for deep work. It supports full Markdown syntax, code blocks, checklists, and auto-saves instantly as you type.

Instant Auto-Save

Never Lose a Word

Every keystroke is saved directly to your local notes database. No save dialogs, no spinners, no lost drafts.

Organization

Bundle Folders

Group notes into collapsible bundle folders (e.g., Units, Lectures, Specs) with drag-and-drop ease.

Clean Hierarchy

Structured Global Export

Exporting all notes generates a clean 4-level Markdown book: # All Space Notes → ## Space → ### Folder → #### Page.

📁 Import & Export Sovereignty
You can drag and drop .md and .txt files directly into the notes sidebar, or use the Command Palette to import and export entire note bundles at will.
Action

Launchpads: 1-Click Multi-Resource Launchers

Stop hunting through browser bookmarks, terminal windows, and nested folders every time you start work. A Launchpad bundles your URLs, local files, scripts, and folders into a single launch deck.

All at Once

1-Click Launch All

Click Launch to simultaneously open all bundled resources in your default browser and native desktop applications.

Quick Access

Pin to Home

Star your most critical Launchpads to display them right at the top of your Home dashboard for instant morning access.

Single Resource Launch

Interactive Path Chips

Click any individual resource chip on the Launchpad card to open just that specific file, folder, or website.

Capture

Floating Quick Note: The Sleek 38px Seamless Pill

Never interrupt your train of thought. Press Ctrl+Shift+Space from anywhere in Windows (or O inside Senku) to summon the floating pill overlay.

Tiny & Sleek

Seamless Unified Pill

Only 38px high with zero border clutter. Sits effortlessly above all your applications without obscuring your screen.

Gold Standard

Downward Auto-Expand

Type as much as you want with Shift+Enter—the pill expands downwards naturally and resets to a slim pill upon saving.

Instant Switch

Toggle Note vs Log

Click the badge or press Tab to toggle instantly between appending to your active Note or posting to Quiet Log.

⚡ Keyboard Ninja Tip
In the overlay: Enter saves & flashes green, Tab switches Note/Log mode, and Esc hides the pill.
Navigation

Command Palette: Complete Keyboard Powerhouse

Press Ctrl+K, Ctrl+P, or single-key P from anywhere in the app to open the fuzzy-search Command Palette.

Speed

Jump to Any View

Switch between Home, Overview, Quiet Log, All Logs, Launchpads, and Notes with instant fuzzy search.

Deep Links

Spaces & Notes

Type the name of any space, launchpad, note, or local file to jump directly to it without clicking around.

Instant Capture

Direct Quick Logging

Type any text and hit Enter to log directly, or prefix with n <text> to append straight into your active note.

Reference

Master Shortcuts Cheatsheet

Senku is designed to be operated 100% from your keyboard. When you are not typing inside an input field or editor, single-key navigation is active.

1. Single-Key View Navigation (When not typing)

Key Action Description
H Home Dashboard Jump to Home overview with pinned launchpads and recent logs.
S Space Overview View active space dashboard with file tree and quick actions.
L Launchpads Full-screen launchpads view to manage and launch resource decks.
G All Logs (#senku) Browse global log stream across all spaces and independent logs.
N Notes Editor Open distraction-free markdown note editor and bundle folders.
P Command Palette Open fuzzy-search command palette to run any action or jump anywhere.
O Quick Note Overlay Open floating 38px mini pill overlay for instant note capture.
R Parent Directory Navigate one folder up in the local file explorer panel.
/ Instant Search Expands search bar and focuses filter input in active view.
? User Guide Open this official guide and master cheatsheet window.

2. Global Hotkeys (Works Everywhere)

Shortcut Scope Action
Ctrl + K / P Global in App Open Command Palette from any screen or modal.
Ctrl + Shift + Space System-Wide (OS) Toggle floating Quick Note pill above all desktop applications.
Ctrl + Enter Global in App Jump directly to log input textarea from anywhere.
Esc Search / Dialogs Clears non-empty search input first; otherwise closes modal or blurs.

3. Floating Overlay Hotkeys

Shortcut Action
Enter Submit note or log immediately (pill flashes green upon save).
Shift + Enter Insert a new line. Pill expands downward automatically.
Tab Toggle mode between active Note and Quiet Log.
Esc Hide the floating pill overlay.
Data Sovereignty

Storage & Portability: Zero Lock-In

Your notes, logs, and configurations are stored as clean JSON and standard Markdown files inside your user profile directory:

%APPDATA%\senku\ (Windows)  |  ~/.config/senku/ (Linux/macOS)

Because Senku does not use proprietary binary formats or closed cloud databases, your data remains readable, editable, and version-controllable with Git or any text editor for decades to come.
