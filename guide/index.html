Home and Rough Note

Senku opens to Home. It shows task counts and shortcuts to Today, Upcoming, Overdue, and Completed, alongside the current Space's file browser. Task names stay in their task views.

The sidebar keeps Home, Rough Note, your Spaces, and settings close at hand. Rough Note is a simple place for thoughts and reminders that do not need to become tasks.

Spaces

A Space connects a name, a main folder, and its own task list. Make a Space for college, a project, personal work, or any setup that suits you.

Use the Spaces list in the sidebar to switch quickly. In Current Space Settings, you can rename the Space, choose a different main folder, and change its resource-opening setting. Your Senku tasks and note stay with the Space when you change its folder.

Deleting a Space removes its Senku data. It does not delete the Windows folder or the files inside it.

Scheduled tasks

Use Scheduled when you know when you want to work. The start time defaults to now; the end defaults to 11:59 PM that day. Both can be changed.

The start time is important: Senku sends a reminder when a Scheduled task starts. If Open linked resources automatically is enabled for the Space, Senku also opens that task's linked resources at the start time.

Task actions

  • Complete moves a finished task to Completed.
  • Reassign saves the current attempt in Completed and creates the next Scheduled task.
  • Snooze moves the start time by 10 minutes, 1 hour, 1 day, or 1 week. Senku sends the reminder again then; linked resources open again too if automatic opening is enabled.
  • Pin keeps a task near the top of task lists. Pinned tasks are not shown on Home.

Editing a Scheduled task's start time resets its reminder for the new time. Linked resources will open again at that time when automatic opening is enabled. Overdue tasks remain available in the Overdue view; reassign one when you are ready to continue.

Use the Home shortcuts to open Today, Upcoming, Overdue, or Completed.

Flexible tasks

Use Flexible for ongoing work with no specific time or reminder, such as completing a Java playlist. Flexible tasks appear in the Flexible and Upcoming views. Complete the task when the playlist is finished.

When you want to schedule a specific session, create a separate Scheduled task, such as “Watch 3 videos,” and choose its start time. Flexible tasks themselves do not send reminders or open linked resources automatically.

Files and linked resources

The file browser shows items inside the current Space's main folder. Open a file with its normal Windows app, copy its path into a task, or rename it after reading the warning.

Tasks can also link to resources outside the main folder, including documents, folders, playlists, and web pages. Use Open resources to launch them manually.

In Space settings, Open linked resources automatically controls whether linked items open when a Scheduled task starts. This setting applies only to that Space.

Your files and data

Senku does not copy or move your files. It stores Space settings, task details, and paths locally in your Windows user data folder. The task list also retains creation and last-updated times.
